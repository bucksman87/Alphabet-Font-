# Square Alphabet — как установить и продавать

Краткий гид для новичка. Шрифт: **Square Alphabet** (файлы `SquareAlphabet.ttf` и `SquareAlphabet.otf`).

## Установка

### macOS
1. Откройте Finder и найдите файл `SquareAlphabet.ttf` (или `.otf`).
2. Дважды кликните по файлу → откроется «Шрифты» (Font Book).
3. Нажмите **Установить шрифт**.
4. Перезапустите Word / Figma / браузер, если программа уже была открыта.

Альтернатива: перетащите файл в приложение **Шрифты**.

### Windows
1. Найдите `SquareAlphabet.ttf` (или `.otf`).
2. Правый клик → **Установить** (или **Установить для всех пользователей**).
3. Либо: Параметры → Персонализация → Шрифты → перетащите файл в окно.
4. Перезапустите программы, где хотите использовать шрифт.

Проверка: откройте любой текстовый редактор и найдите в списке шрифтов **Square Alphabet**.

## Где работает шрифт

После установки на компьютере шрифт доступен там, где есть выбор шрифта:

| Где | Как |
|-----|-----|
| **Microsoft Word / Google Docs** | Формат → Шрифт → Square Alphabet |
| **Canva** | Загрузите `.ttf` в Brand Kit / загруженные шрифты (в платных планах удобнее) |
| **Figma / Adobe Illustrator / Photoshop** | Появится в списке шрифтов после установки в систему |
| **PowerPoint / Keynote** | Как обычный системный шрифт |
| **Instagram / TikTok / телефон** | Системный `.ttf` с Mac/Windows **сам на телефон не ставится**. Для сторис/постов: сделайте макет в Canva/Figma и экспортируйте картинку |

Это **декоративный** квадратный шрифт (A–Z / a–z одинаковые). Для длинных текстов неудобен — лучше для логотипов, заголовков, постеров, обложек.

## Права: коротко о законе

Вы **сами нарисовали** эти знаки — по умолчанию права на рисунок и на сделанный из него шрифт принадлежат вам.

Перед продажей:
- не копируйте чужие шрифты «один в один»;
- на площадках прочитайте их правила (лицензия для покупателя, коммерческое использование);
- если шрифт делали вместе с кем-то — договоритесь письменно, кто владелец.

Это не юридическая консультация, а ориентир. При больших продажах лучше спросить юриста.

## Как продавать новичку

### Площадки
1. **Gumroad** — проще всего начать: аккаунт → продукт (цифровой файл) → цена → ссылка.
2. **Creative Market** — аудитория дизайнеров; нужна заявка/проверка, зато «шрифтовый» трафик.
3. **Etsy** — цифровой листинг (Digital download); хорошо заходит через мокапы и SEO-название.

Можно начать с Gumroad + Etsy, потом добавить Creative Market.

### Цена (ориентир)
- Один начертание (Regular), только латиница A–Z: примерно **$8–25**.
- Если сделаете пакет (TTF+OTF, лицензия для логотипов, мокапы): **$15–40**.
- Скидка на старте (launch price) помогает первым продажам.

Не ставьте $1 «навсегда» — потом сложно поднять цену; лучше временная скидка.

### Что положить в листинг
- Файлы: `SquareAlphabet.ttf`, `SquareAlphabet.otf`, короткий `font-readme` / лицензия.
- **Мокапы** (картинки «как выглядит»): алфавит A–Z, слово-пример, постер, логотип на футболке/визитке. Можно сделать в Canva или Figma.
- Текст: название, для чего шрифт (постер, бренд, обложка), какие символы есть (A–Z, a–z = те же, пробел), ОС (Mac/Windows).
- Лицензия простыми словами: например «для личных и коммерческих проектов покупателя; нельзя перепродавать сам файл шрифта».

### Мини-чеклист перед публикацией
- [ ] Шрифт ставится на Mac и Windows  
- [ ] В превью видно все буквы A–Z  
- [ ] В архиве есть TTF (и OTF) + текст лицензии  
- [ ] Цена и площадка выбраны  
- [ ] 3–6 мокапов загружены  

Удачи — квадратный рукописный алфавит хорошо смотрится на обложках и в соцсетях.
